# Getting Started

1. If you are working on a computing cluster like UW's Hyak, the [Hyak
Onboarding](HyakOnboarding.md) should be of most help for getting started.
In summary, you need to set up the included conda environment and, for
animations, ensure you have ffmpeg installed.
2. Some of the planar graphics scripts require a file "apis.py" which can
   contain a Stadia maps key, if you have one. See the example file
   `apis-example.py`. If the key is missing, the scripts will fall back on
   an openly available alternate basemap.
3. Once your environment is configured, see [Running the Code](running.md).
