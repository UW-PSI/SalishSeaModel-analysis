# Workflow Examples

In this directory are some complete examples of processing workflows
using simple bash scripts and a case file.

1. `ecology_2021`: ongoing work to improve processing of a reproduction
of Ecology's Ahmed 2021 runs.
2. `ecology_2025` (coming soon): ongoing work to replicate Ecology's
Figueroa-Kaminsky model setup and processing so PSI's Whidbey report can
be updated.
3. `metabolic_index`: New work submitted for publication that uses model
outputs to compute the metabolic index and habitat compression for several
species.
